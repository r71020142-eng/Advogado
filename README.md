1. Acesse o repositório: [https://github.com/r71020142-eng/Advogado](https://github.com/r71020142-eng/Advogado)
2. Clique na aba **Settings** (Configurações) no topo direito.
3. No menu lateral esquerdo, clique em **Pages** (dentro da seção "Code and automation").
4. Em **Build and deployment** > **Branch**:
   - Selecione a branch `main`.
   - Mantenha a pasta como `/(root)`.
   - Clique em **Save**.
5. Aguarde cerca de 1 a 2 minutos e atualize a página. O GitHub exibirá o link público:
   `https://r71020142-eng.github.io/Advogado/`
6. Pronto! O site estará online com HTTPS gratuito e acessível de qualquer celular, tablet ou computador.
